# Popular VS Code Themes - Reference Guide

## Top Rated VS Code Themes (2024-2025)

Based on community ratings, downloads, stars, and user reviews:

### Dark Themes (Most Popular Category)

1. **One Dark Pro** - Based on Atom's One Dark, most downloaded theme
   - Stars: 4,500+ | Downloads: 10M+
   - Dark gray backgrounds, purple/blue accents
   
2. **Dracula Official** - Vibrant purple/pink accent on dark background
   - Stars: 8,500+ | Popular for color coding
   
3. **Material Theme** - Material Design inspired
   - Darker UI, vibrant colors, modern look

4. **Atom One Dark** - Original Atom theme foundation
   - Subtle grays, blue/purple highlights

5. **Nord** - Arctic/Noor palette, cool blue-gray tones
   - Stars: 3,000+ | Popular for eye comfort

6. **Palenight Theme** - Evolution of One Dark, more vibrant
   
7. **Synthwave '84** - Retro neon cyberpunk style (highly rated)
   - Bright neon colors on very dark background

8. **Tokyo Night** - Clean dark purple/blue tones
   - Stars trending upward for 2025

9. **Night Owl** - High contrast, designed for night owls
   - Stars: 4,000+ (by Sarah Drasner)

10. **Cobalt2** - Deep blue background with cyan/magenta accents

### Light Themes

1. **Atom One Light** - Official Atom light theme
   
2. **GitHub Theme** - Matches GitHub.com appearance
   
3. **Solarized Light/Dark** - Color theory based, eye-protective
   - Stars: 2,500+ | Popular for long sessions

4. **Ayu Dark/Light** - Japanese "peace" concept, modern
   - Yellow/cyan/purple accents depending on variant
