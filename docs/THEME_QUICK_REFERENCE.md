## How to Import in 3 Steps

1. **Open MAXplorer** → Settings (⚙️) → **Appearance**

2. **Click "Import Theme"** → Browse to: `/themes/[theme-name].maxTheme`

3. **Preview & Install** → Done!

### Or Right-Click Direct File (if supported):
```bash
Right-click any .maxTheme file → Select "Install in MAXplorer"
```
